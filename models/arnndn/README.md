## Licensing Status

According to the upstream repository author
([GregorR/rnnoise-models README](https://github.com/GregorR/rnnoise-models/blob/master/README.md)):

> "The model files are not subject to copyright, as they are simply a dump of
> parameters obtained from an automated training process."

The underlying `rnnoise-nu` software architecture is distributed under a BSD
3-Clause license, but that license applies to the software implementation,
whereas these model parameter files are uncopyrightable machine-generated neural
network weights.
