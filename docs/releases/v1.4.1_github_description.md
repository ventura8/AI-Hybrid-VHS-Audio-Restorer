# v1.4.1

## Highlights

- **The `auto` scanner's memory bounded (issue #14).** On the longest input
  the profile reads (240 s), the flatness reading peaked at 593 MB and the
  probe reading at 140 MB; they now hold 48 MB and 59 MB. Every number the
  routing thresholds were calibrated on is equal bit for bit on 226 real
  recordings, so `auto` chooses exactly as before.

- **Only this release's installers on the release page.** Every release up
  to v1.4.0 also carried a stale `v1.1.0-linux.deb`; it is gone.

- **Dependencies on their latest releases**, audio-separator 0.48.0 (safe
  checkpoint loading, checksum-verified models) and transformers 5.22.1
  among them. The torch set stays at 2.14.1: torch 2.15.0 (cu132 only)
  audibly changes `auto_pure_linear`'s output and waits for its own
  confirmation.

## Upgrade Notes

Nothing to change: `auto_pure_linear` and `cathar` render the same bytes as
v1.4.0, and the settings and routing are unchanged. audio-separator 0.48.0
downloads again a model file whose bytes differ from the checksum it
publishes for that name.
