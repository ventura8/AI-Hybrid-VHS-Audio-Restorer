# v1.3.8

v1.3.7 was tagged but never published: its release build failed on Windows. v1.3.8
ships everything below plus that fix.

## Highlights

- **A fuller 's' on `auto_pure_linear`.** The presence shelf at 7.5 kHz drops
  from +2 dB to +1 dB, chosen by ear in an A/B on four real tapes. The
  denoiser was not thinning the 's'; the shelf was brightening everything
  above 4 kHz.

- **SonarQube Cloud: quality gate OK, 0 issues, 95.9% coverage on main.**
  196 findings from main's first full analysis are fixed at the source, with
  no suppressions, including 33 vulnerabilities where a command-line argument
  reached a file or a subprocess unchecked.

- **Command-line values are checked where they are used.** The developer
  scripts confine every path to the repository, the temp directory or a root
  in `AI_RESTORE_DATA_ROOTS`, and rebuild every number and name before it
  reaches ffmpeg.

- **The tuning loop skips knobs that cannot move the audio**, and the sibilant
  guard's fricative threshold is a setting and a loop knob.

- 21 dependencies and three CI actions on their latest releases. Deferred: the
  torch set, transformers, numba and three lint tools, which change the
  dependency graph.

- The Windows installer smoke test no longer refuses an install directory the
  installer has yet to create (the failure that kept v1.3.7 unpublished).

## Upgrade Notes

`auto_pure_linear` is 0.7-1 dB darker above 8 kHz; `linear_air_gain_db: 2.0`
restores the earlier shelf. `cathar` is unchanged (bit-identical). Developer
scripts that read tapes outside the repository need `AI_RESTORE_DATA_ROOTS`
set to their folder; the restorer itself is not affected.
