# AI Hybrid VHS Audio Restorer v1.2.1 - Auto Pure Linear Overtakes Cathar

## Highlights

- `auto_pure_linear` now removes more tape noise than `cathar` while disturbing
  the programme less, across 136 Internet Archive clips in both PAL and NTSC. In
  v1.2.0 it lost on both counts.
- Noise floor regressions in that mode fall from 47% of clips to 3%, and on
  NTSC from 52% to 4%.
- The mode gets a noise probe of its own at 2.5 s, which accounts for
  essentially the whole improvement.
- A learned per-bin blend repairs spectral over-subtraction instead of trading
  fidelity against it.
- `auto_pure_linear` now repairs physical tape damage too -- crackle, dropouts,
  saturation and azimuth skew, each gated on its own defect. It previously
  repaired none of it. Three further stages were measured and rejected for
  making undamaged material worse.
- A subtraction factor gated on tonality, which closes the one fidelity gap
  `cathar` still held; DeepFilterNet3 as an opt-in neural stage, off by default
  on real-tape evidence.
- A fixture set calibrated to real tape that agrees with all four real-tape
  verdicts the realism check runs and covers every fault in the defect catalog
  a fixture can inject (sibilance and a constant speed error excepted) plus the
  ten the preservation literature adds; the corpus behind it grew to 1,982
  clips of 847 tapes.
- `cathar` is byte-for-byte unchanged from v1.2.0.

| Metric (median, 136 clips) | `cathar` | `auto_pure_linear` |
| :--- | ---: | ---: |
| Noise removed (dB, higher better) | 6.02 | **8.75** |
| Programme deviation (dB, lower better) | 0.44 | **0.33** |

## Upgrade Notes

`cathar` remains the default and its output is unchanged. Consider
`auto_pure_linear` where tape hiss is the main complaint -- it now repairs
crackle, dropouts, clipping and azimuth skew too. Keep `cathar` for spectral
spikes, plosive-heavy dialogue, or an unknown tape. Neither mode removes mains
hum by default on this corpus; the v1.2.0 claim that `cathar` did is withdrawn.

No configuration changes are required.
