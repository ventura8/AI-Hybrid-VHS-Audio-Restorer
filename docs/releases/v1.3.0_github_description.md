# AI Hybrid VHS Audio Restorer v1.3.0 - Auto Pure Linear Closes the Coverage Gap

## Highlights

This release ships instead of v1.2.1, which was never released: that branch's
work -- the calibrated fixture set that predicts real tape, the trade metric
and its corpus, and the mode's gains recorded in `docs/releases/v1.2.1.md` --
is carried here, and every v1.2.1 figure quoted below is that branch's
measurement, not a released version's.

- `auto_pure_linear` now removes mains hum, which neither mode did on real
  tape: a canceller of its own tracks each mains harmonic at the frequency it
  actually sits at and subtracts it ahead of the noise probe. On the 33 readable
  corpus tapes that carry hum it removes a median 1.19 dB of harmonic
  excess against `cathar`'s -0.74, and takes the lines themselves down 3.04
  dB against 0.75, with the broadband trade unmoved.
- Plosives are tamed as events, where `cathar`'s `deplosive` was measured
  harmful on undamaged material: 0.89 dB recovered inside the blasts at 0.03
  dB of collateral, free on real tape.
- On the full corpus 10.10 dB of noise removed at 0.31 dB of deviation
  against `cathar`'s 6.02 at 0.44, winning both on 70 of 136 clips against
  8; the 1.35 dB over v1.2.1 is a noise probe lengthened to 4 s on the
  corpus's own evidence.
- **`auto_pure_linear` is the default restoration mode from this release.**
  It leads on every row measured on real tape; `cathar` is unchanged,
  selectable, and one line of `config.yaml` away.
- Every other candidate was measured on real tape and held back with its
  numbers in the configuration: a per-bin MMSE log-spectral suppressor, the
  Mel-Roformer and Resemble denoisers and a canceller for persistent lines
  above 4 kHz. The noise probe grew from 2.5 s to 4 s on the same evidence.
- A perceptual cross-check, DNSMOS P.835 on every restored clip, beside the
  trade metric and never in its place: the mode reads ahead of `cathar` on
  140 of 174 clips.
- `cathar` is byte-for-byte unchanged from v1.2.1.

| Metric (median, 136 clips) | `cathar` | `auto_pure_linear` |
| :--- | ---: | ---: |
| Noise removed (dB, higher better) | 6.02 | **10.10** |
| Programme deviation (dB, lower better) | 0.44 | **0.31** |

## Upgrade Notes

`auto_pure_linear` is now the default `process_mode`. A configuration that
names the mode explicitly is unaffected; to keep the previous default, set
`process_mode: cathar`. `cathar`'s output is unchanged. The new `apl_*`
settings all have working defaults and are documented in
`docs/configuration.md`; the DNSMOS cross-check needs two model files that
`scripts/download_dnsmos.py` fetches, and nothing in the restoration depends
on them.
