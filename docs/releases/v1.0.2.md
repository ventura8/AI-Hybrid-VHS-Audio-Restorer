# v1.0.2

## Release Summary

This release hardens local and CI quality enforcement, stabilizes Poetry
environment handling, and improves coverage/reporting reliability.

## Highlights

- Added strict per-file coverage policy: every measured file must be at least
  90%.
- Enforced per-file coverage locally and in CI via
  `tests/tooling/quality_gate.py`.
- Updated `run_pipeline_locally.ps1` to include explicit per-file coverage gate
  execution.
- Updated CI workflow to fail fast on per-file coverage regressions.
- Increased `modules/utils.py` coverage to pass strict branch-aware threshold.
- Enforced `process_mode` runtime behavior end-to-end:
  - `hybrid`: separation + vocal enhancement + background denoise + sync + mix.
  - `denoise_only`: full-audio denoise + sync + remux (no
    separation/enhancement).
- Changed shipped `config.yaml` default `process_mode` from `hybrid` to
  `denoise_only` as a user-visible behavior change. Existing users relying on
  the default configuration now run denoise-only (no separation/enhancement)
  unless they explicitly set `process_mode: "hybrid"`.
- Fixed `denoise_only` flow reliability and validation coverage to prevent
  regressions in full-audio denoise + remux execution.
- Standardized mode-specific output naming:
  - `*_Hybrid_Cleaned.<ext>` for `hybrid`
  - `*_Denoised_Cleaned.<ext>` for `denoise_only`
- Updated documentation and Mermaid pipeline schemas to reflect both mode
  branches and output contracts.

## Dependency Updates

- Migrated dependency management to Poetry lock-based flow and refreshed
  runtime/dev dependency sets.
- Preserved and documented CUDA 13.2 runtime baseline for Windows GPU execution.
- Locked GPU stack to the `pytorch-cu132` index for CUDA 13.2-compatible wheels.
- Updated key GPU/runtime dependencies:
  - `torch==2.13.0+cu132` (CUDA 13.2 source index)
  - `torchvision==0.28.0+cu132` (CUDA 13.2 source index)
  - `torchaudio==2.11.0` (official wheel compatible with the locked
    `torch==2.13.0+cu132` stack)
  - `nvidia-cudnn-cu13==9.20.0.48`
  - `nvidia-cublas==13.4.0.1`
- Kept `numpy` constrained to `<2.5` to remain compatible with the current
  `audio-separator` dependency chain.

## Reliability Improvements

- Improved virtual environment normalization in local scripts so external
  activated environments do not break Poetry execution flow.
- Preserved deterministic Poetry usage for local and CI quality gates.

## Quality and Reporting

- Maintained total coverage gate at 90% while adding strict per-file guard.
- Kept coverage artifact generation and badge refresh in the canonical local
  pipeline.
