# v1.1.0

## Release Summary

This release introduces complete cross-platform support (Linux, macOS with Apple
Silicon MPS acceleration, and Windows), major audio restoration intelligence,
multi-pass cascaded restoration (`multipass_auto`, `auto`), fine-tuned
`auto_pure` speech neural denoising, native VHS DSP filtering (`vhs_native`,
`auto_ffmpeg_native`), ARNNDN neural speech denoising (`arnndn_speech`),
surgical tone notching (CRT flyback, enclosure resonance, DC offset nulling,
stereo balance leveling), dynamic speech polish (de-esser, background dynamic
expander, EBU R128 loudness normalization), unattended multi-folder batch
processing (`scripts/batch_restore.py`), and a comprehensive Antigravity
workspace skills suite in `.agents/skills/`.

## Highlights

- **Cross-Platform Linux & macOS Architecture**:
  - Full native runtime and testing support across Ubuntu/Debian/Fedora Linux,
    macOS (Apple Silicon M1/M2/M3/M4 with Metal Performance Shaders / MPS
    acceleration and Intel x86_64), and Windows.
  - Native POSIX installation (`install_dependencies.sh`) and execution
    (`start.sh`) scripts with automatic interpreter discovery (`python3.12` /
    `uv`).
  - Dynamic linker management (`LD_LIBRARY_PATH` and `DYLD_LIBRARY_PATH`) for
    in-project virtual environment shared libraries.
  - Multi-OS containerized test harness (`docker/Dockerfile.ubuntu`,
    `docker/docker-compose.test.yml`, `docker/run_cross_platform_tests.sh`) and
    cross-platform GitHub Actions CI matrix.
- **Fine-Tuned `auto_pure`, `multipass_auto` & `auto` Intelligent Engines**:
  - Dual-resolution macro & micro acoustic scanning across speech, music,
    ambient texture, noise floor, rumble, and mains hum.
  - Dedicated speech-stem neural denoising (`UVR-DeNoise-Lite`) without
    generative vocoder artifacts, leaving natural timbre and formants.
  - Background stem ambient and harmonic preservation with downward dynamic
    expansion.
  - Unattended multi-folder batch runner (`scripts/batch_restore.py`) with
    atomic output promotion and resume protection.
- **Precision Analog & Hardware Pre-Conditioning**:
  - DC Offset Voltage Nulling (2 Hz sub-audible highpass filter).
  - Stereo Channel Balance Auto-Leveling (Left vs Right RMS balancing).
  - Stereo Azimuth Delay Alignment (sub-millisecond cross-correlation delay).
  - Analog Preamp De-Clipping (`adeclip`).
  - CRT Horizontal Flyback Line Whine Notch (15.625 kHz PAL / 15.734 kHz NTSC).
  - Camcorder Enclosure Acoustic Resonance Notching (1.5 kHz – 3.5 kHz).
- **Mastering & Dynamic Audio Polish**:
  - Neural Speech Sibilance Control via dynamic vocal de-esser (`deesser`).
  - Sub-threshold Downward Dynamic Noise Expander (`compand`).
  - Broadcast EBU R128 Loudness Normalization & True-Peak Limiter (-16 LUFS /
    -1.0 dBTP).
  - Dual-Track Archival Container Preservation (retaining untouched source audio
    as secondary track, disabled by default, enabled when
    `preserve_original_audio_track` is true).
- **`vhs_native` & `auto_ffmpeg_native` DSP Engines**:
  - Native multi-threaded FFmpeg DSP filter pipeline (`highpass`, `adeclick`,
    `afftdn`, `bandreject`).
- **`arnndn_speech` Neural Denoising**:
  - RNNoise recurrent neural network speech denoiser with local tracking for
    `models/arnndn/cb.rnnn` and verified auto-download discovery.
- **Antigravity Agent Rules & Workspace Skills**:
  - Expanded `AGENTS.md` and complete Antigravity workspace skills suite under
    `.agents/skills/` with workflow playbooks under `.agent/workflows/`.
- **Quality Gates & Code Complexity**:
  - 100% Radon Cyclomatic Complexity Grade A (≤ 5) and Maintainability
    Index Grade A (≥ 20) across every source and test module.
  - 399 unit and integration tests passing with 94.17% total coverage
    (strict ≥ 90.00% per-file coverage gate).

## Restoration Modes Matrix

- **`auto`** (`*_Auto_Cleaned.<ext>`):
  - Intelligent single-click end-to-end restoration with acoustic profiling.
- **`multipass_auto`** (`*_MultiPass_Cleaned.<ext>`):
  - Maximum quality 4-pass cascaded restoration.
- **`auto_pure`** (`*_Pure_Cleaned.<ext>`):
  - Multi-step pure speech & ambient denoising without vocoder synthesis.
- **`hybrid`** (`*_Hybrid_Cleaned.<ext>`):
  - Full 2-stem vocal/background separation (BS-Roformer) + Resemble-Enhance.
- **`denoise_only`** (`*_Denoised_Cleaned.<ext>`):
  - Fast AI broadband denoising (UVR-DeNoise-Lite) without stem separation.
- **`auto_ffmpeg_native`** (`*_AutoFFmpeg_Cleaned.<ext>`):
  - Adaptive native FFmpeg DSP filtering auto-tuned to measured noise profile.
- **`vhs_native`** (`*_FFmpeg_Cleaned.<ext>`):
  - Fixed native FFmpeg multi-threaded DSP filter chain.
- **`arnndn_speech`** (`*_Speech_Cleaned.<ext>`):
  - Deep-learning RNNoise speech denoiser for dialogue.
