# v1.0.3

## Release Summary

This release upgrades the validation pipeline with stricter local/CI parity,
adds TOML and security gates, improves runtime resiliency for GPU and DTW paths,
and hardens docs/agent guidance around the canonical quality flow.

## Highlights

- Added Python formatting gates (`black`, `isort`) to local and CI pipelines.
- Added TOML formatting gate using Poetry-managed `taplo`.
- Added security gates with `bandit -ll -ii` and `pip-audit` in local and CI.
- Switched quality environment install from `poetry install` to
  `poetry sync --only main,dev --no-root` for deterministic tool parity.
- Added local pipeline Poetry re-bootstrap step after sync to preserve command
  availability across the full run.
- Extended Radon reporting scope to include test-suite files
  (`tests/conftest.py`, `tests/unit`, `tests/integration`) and added strict pass
  gates:
  - `tests/tooling/radon_cc_gate.py`
  - `tests/tooling/radon_mi_gate.py`
- Updated strict gate documentation across project docs and agent files.

## Runtime and Reliability Improvements

- Improved CUDA environment handling in hardware detection and fallback paths:
  - Added explicit child-device and CUDA env propagation helpers.
  - Hardened CPU fallback behavior and environment cleanup.
- Updated vocal enhancement execution to pass explicit CUDA env/device context
  into subprocess command execution.
- Hardened DTW parallel execution and cancellation behavior:
  - Added cancellation token propagation and executor shutdown safety.
  - Improved failure propagation in fallback write paths.
- Improved audio file robustness utilities:
  - OSError-safe metadata checks in audio candidate detection.
  - Atomic replacement with `os.replace` for final artifact swaps.
  - Dependency probe timeout/error handling for external tool checks.

## Test and Tooling Enhancements

- Added/updated tests for:
  - DTW cancellation and fallback behavior.
  - Hardware env propagation and CPU fallback reset behavior.
  - Processing CUDA command/env forwarding.
  - Utility timeout, OSError, and logging edge cases.
  - Integration smoke assertions and refactored helper flows.
- Improved patching utility behavior in `scripts/apply_patches.py`:
  - Robust chunk/overlap upgrade logic.
  - Better already-patched detection.

## Dependency and Configuration Updates

- Added/updated dev tooling dependencies:
  - `black`, `isort`, `taplo`, `bandit`, `pip-audit`
- Updated ML dependency target:
  - `transformers` upgraded to `^5.3.0`
- Added `tool.black` and `tool.isort` configuration in `pyproject.toml`.

## Validation

Canonical local gate:

```powershell
./run_pipeline_locally.ps1
```

This run validates PowerShell lint, Python format/lint checks, TOML checks,
security scans, Radon reports/gates, Markdown quality, pytest coverage gates,
and badge regeneration.
