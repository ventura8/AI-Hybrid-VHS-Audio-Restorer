# AI Hybrid VHS Audio Restorer v1.1.1 - Linear Full-Mix Pure Restoration

## What is new

- Adds `auto_pure_linear`, a fully supported full-mix pure-denoising mode.
- Reuses acoustic profiling, analog pre-conditioning, sync, mastering, and
  remuxing from `auto_pure`, while intentionally skipping stem separation.
- Writes `*_PureLinear_Cleaned.<ext>` output files.
- Adds the reproducible stem-separation A/B pilot runner and blinded review
  materials for evidence-based selection between `auto_pure` and the linear
  mode.
