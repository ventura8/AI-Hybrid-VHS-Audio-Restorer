# v1.2.0

## Release Summary

Version 1.2.0 is a major restoration and validation release. It adds adaptive
native VHS DSP, neural RNNoise dialogue restoration, resilient multi-pass AI
processing, cross-platform packaging and installation paths, and an opt-in
hardware-validation matrix built from deterministic Piper speech.

## Restoration Engine

- Adds `auto_ffmpeg_native`, `vhs_native`, and `arnndn_speech` execution modes.
- Adds `cathar` and `cathar_vhs` pure-Rust DSP restoration paths.
- Expands analog pre-conditioning with balance correction, azimuth alignment,
  de-clicking, de-clipping, hum treatment, and line-whistle analysis.
- Adds adaptive acoustic scanning and video-line-referenced flutter detection.
- Preserves 32-bit float intermediates, EBU R128 loudness processing, true-peak
  limiting, stream-copy video remuxing, and mode-specific output suffixes.

## Hardware Validation

- Adds portable PyTorch, ONNX Runtime, VRAM, and accelerator audit scripts.
- Adds deterministic short, mid, and long-form defected fixture generation.
- Adds a checksum-pinned Piper catalog of 50 language-native voices.
- Adds multilingual hardware smoke, validation, and long-form stress tests.
- Keeps physical hardware runs opt-in so ordinary CI remains CPU-only and
  model-free.

## Tooling and Distribution

- Adds repeatable tape analysis, quality comparison, tuning, batch-restoration,
  and installed-executable validation tooling.
- Adds Linux, macOS, and Windows package or installer workflows.
- Extends CI, local quality gates, agent skills, workflows, and documentation.

## Upgrade Notes

`auto_pure_linear` remains the default full-mix archival mode. Use native modes
when a fast FFmpeg-only workflow is preferred, or select AI modes when their
model dependencies are available. Hardware fixture generation downloads Piper
voices on demand and stores them only under ignored `artifacts/` paths.
