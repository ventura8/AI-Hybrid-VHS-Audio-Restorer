# v1.4.2

## Highlights

- **torch 2.15.0 on CUDA 13.2**, adopted on the AI ear's confirmation. It
  moves `auto_pure_linear`'s output by a hair; on 235 Internet Archive clips,
  realistic-v2's 92 fixtures and the four Tata tapes the ear reads no change
  (0 material guard trips, distance to target +0.00 dB, every Tata reading
  within 0.08 dB). `cathar` is unchanged.

- **The AI human ear decides alone.** No more live listening sessions: a
  default, or a dependency that moves the output, ships on the ear's
  confirmation (the Tata readings, one IA-corpus and one realistic-v2 run).

The installers pull the cu132 torch set; GPU inference needs an NVIDIA
driver with CUDA 13.2 support. No setting changed.
