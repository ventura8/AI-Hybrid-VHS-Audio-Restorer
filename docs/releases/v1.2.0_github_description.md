# AI Hybrid VHS Audio Restorer v1.2.0 - Multilingual Hardware Validation

## Highlights

- New adaptive FFmpeg, RNNoise, and Cathar restoration paths alongside the
  existing AI modes.
- Enhanced VHS-specific analog repair: hum, CRT whistle, rumble, clicks,
  clipping, stereo imbalance, azimuth skew, and transport drift.
- New opt-in hardware validation suite with accelerator auditing, RTF and VRAM
  reporting, and deterministic Piper speech fixtures.
- Multilingual matrix covering 50 checksum-pinned Piper voices across short,
  mid, and long-form validation profiles.
- Expanded cross-platform installers, CI gates, tuning tools, documentation,
  agent skills, and release workflows.

## Thanks

Special thanks to [vbasky/cathar](https://github.com/vbasky/cathar) for its
transparent pure-Rust audio-restoration toolkit, which helped inspire the
Cathar-native DSP direction in this release.

## Upgrade Notes

`auto_pure_linear` remains the default. Generate multilingual fixtures with:

```powershell
poetry run python scripts/generate_audio_matrix.py core --language all
```
